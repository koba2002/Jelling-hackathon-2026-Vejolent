# images/

The game shows a photo of each copy next to its story, and a Viking illustration in the background.
These pictures belong to their owners (the museum material for the Techathon), so they are **not**
included in this repository.

To use your own, put JPG files here with these names. Every file is optional: if one is missing,
that part of the screen is simply left out.

| File | Shown |
|---|---|
| `vikings.jpg` | Background illustration behind the text |
| `tokyo.jpg`, `paris.jpg`, `utrecht.jpg`, `hvidovre.jpg`, `yorba.jpg`, `viborg.jpg`, `london.jpg`, `rouen.jpg`, `varde.jpg` | Photo of that copy today, next to its story |
